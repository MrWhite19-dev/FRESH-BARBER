FRESH BARBER ANGRE — SITE VITRINE + TABLEAU DE BORD

CONTENU
- index.html : site vitrine de présentation, prestations sans prix, coordonnées, horaires et formulaire de demande de réservation.
- dashboard.html : tableau de bord pour modifier les informations du salon, les descriptions des prestations et les horaires jour par jour.
- style.css / dashboard.css : styles responsive.
- script.js / site-settings.js / dashboard.js : interactions et sauvegarde locale.

UTILISATION
1. Décompresser le ZIP.
2. Ouvrir index.html dans un navigateur pour voir le site.
3. Ouvrir dashboard.html pour modifier les informations.
4. Dans le tableau de bord, enregistrer les modifications. Elles sont stockées dans le navigateur utilisé.
5. Le formulaire de réservation prépare un message WhatsApp. Le client envoie la demande au salon; le salon doit confirmer le créneau.

IMPORTANT
Cette version est une maquette fonctionnelle côté navigateur. Elle ne comporte pas de boutique, panier, favoris, commandes en ligne, paiement ou tarifs. Les données du tableau de bord ne sont pas partagées entre visiteurs ou appareils. Pour un site réellement administrable en ligne avec gestion centralisée des réservations, connecter un backend et une base de données.
